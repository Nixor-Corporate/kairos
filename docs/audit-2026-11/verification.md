## Performance measurements

The synthetic two-student HTTP workbook returned about 10 KB and took 121 ms including openpyxl parsing. A separate CLI run with 25,000 attempts took 1.79 seconds, reported 2.0 MiB of peak PHP allocator usage, and produced an 807,077-byte archive. Openpyxl counted all 25,000 data rows. The small course and load fixture are different workloads. No before/after production request metric is available, and the PHP allocator measure excludes database-server and native-library memory. Profile cPanel worker latency, native memory and temporary disk while exporting the largest authorized course. Use query count and p50/p95 comparisons on synthetic rooms before changing queue request patterns.

## Manual QA checklist

- Incident owner verifies rotation, GitHub protections, hosting provenance and HTTPS redirects before staged rollout.
- With assigned manager and admin fixtures, configure rating-only, comment-only and both. Reorder, rename, deactivate and reopen choices. Open the same course in two tabs and confirm stale policy errors.
- With TA and student fixtures, complete, reverse and retry a task. Confirm history and unchanged prior ratings, forbidden cross-course operations, record counts and student-visible status after reconnect.
- Use 320, 375, 768 and wide desktop, both themes, keyboard, zoom and a real screen reader. Verify focus moves into and back from dialogs, required status is clear, and export errors and results are announced.
- Export two unrelated courses and inspect row counts against authorized staging data in desktop Excel. Test course size, filename, temporary storage and download timeout.
- In staging, verify Google domain sign-in, application password flow, cookie persistence and logout, pre-enrollment, concurrent accept/leave, projector lighting, browser notification/audio permissions, realtime disconnect/reconnect, quizzes and grade release, analytics and Drive upload/preview permissions. Check behavior in multiple tabs.
- Check hosted logs for recoverable database lock or export errors and confirm private debug and diagnostics remain disabled.
