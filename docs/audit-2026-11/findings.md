# Findings and issue-to-code traceability

Feedback references use **S** for `Kairos Student` and **T** for `Kairos TA`. Each number is the physical spreadsheet row. “Confirmed” means the behavior or missing guard is visible in current source or read-only service metadata. “Reproduced” requires an observed test. A code finding can explain a survey symptom without establishing that respondent's particular cause.
